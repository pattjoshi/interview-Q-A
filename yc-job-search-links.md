## 4. Job ID trick

Job URLs look like `workatastartup.com/jobs/118154`. IDs go up in order, so **higher number = newer job**.
The newest ID seen on 1 Nov 2026 was **118154**. Anything above it is newer.

- [Job 118154](https://www.workatastartup.com/jobs/118154)

## 5. URL cheat sheet

| Parameter | Meaning |
|---|---|
| `sortBy=created_desc` | Newest jobs first |
| `sortBy=most_active` | Recently active founders first |
| `query=LLM` | Keyword search (title, tech stack, company) |
| `role=eng` | Engineering |
| `role_type=ai` | AI engineer (also `fullstack`, `backend`) |
| `locations=IN` | India |
| `remote=yes` | Remote OK |
| `minExperience=1&minExperience=3` | 1–3 and 3–6 years |
| `hasSalary=true` | Salary range listed |
| `interviewProcess=true` | Interview steps listed |

## 6. Gotchas

- `role_type=ai` + `locations=IN` returned **0 results**. For India, use `query=LLM` instead (19 startups).
- Typing a search switches sorting to relevance. Set `sortBy=created_desc` again in the URL.
- "No specific jobs listed" companies still accept applications, and fewer people apply there.

## 7. Daily routine (15 min)

1. Open the first 3 links in section 1.
2. Apply to anything new at the top, with a 2–3 line note to the founder.
3. Open one "most active founders" link and apply to 2 more.
4. Note the highest job ID you saw, so tomorrow you know what's new.
